# Voydar Beacon image

Build scripts for the Voydar Beacon Raspberry Pi image: turn a Raspberry Pi and a USB radio into an AIS (and ADS-B) receiver for the [Voydar Beacon network](https://www.voydar.com/contribute).

- **Download the image:** see [Releases](../../releases). Check the sha256 against the one on [www.voydar.com/contribute](https://www.voydar.com/contribute).
- **How it works and how to build it yourself:** [README.md](README.md).
- **Help and questions:** the Receivers & Beacon board in the [Voydar community](https://www.voydar.com/community).

This repository is a published copy of `scripts/beacon-image/` from the Voydar platform. The scripts in it are © The Schoeller Group LLC. The image they build contains open-source components under their own licences; each release lists them, with their source.
